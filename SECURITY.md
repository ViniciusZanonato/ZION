# Security Policy

## Reporting Issues

If you find a security issue in ZION, please open a private report through GitHub security advisories when available, or contact the repository owner directly.

Do not publish exploit details before the issue has been reviewed.

## Scope

Security reports should focus on:

- unsafe command execution
- secret exposure
- path traversal or arbitrary file writes
- dependency vulnerabilities with a practical impact
- unsafe behavior in OSINT or pentest helpers

ZION is experimental software. Use it only in environments where you understand the risks, and only run security research commands against systems you are authorized to test.
